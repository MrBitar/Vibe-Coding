## Incremental Testing Before Full Runs

- After writing any code that performs a repeated or bulk operation, always test it on a small iteration first before running the full task.
- Example: if asked to run something 100 times, first run it 5 times, verify the output is correct, and only then proceed to run the full 100 iterations.
- Confirm the small-scale test works correctly before scaling up.
