# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project

A Solitaire card game.

## Requirements

- **Window**: The game window must launch maximized by default.
- **Research before building**: Before implementing game logic, review the rules of Solitaire (Klondike) — card setup, tableau/foundation/stock/waste piles, valid moves, and win conditions — so the implementation is rules-accurate.
- **Test before publishing**: Before publishing or declaring the game done, actually run and play through the game (deal, valid/invalid moves, win/lose states) to confirm it works. Don't rely on code review alone.
